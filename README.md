## 语法检察官

一个会自我进化的 Python 智能体。主动检查、主动修复、**主动学习**。

### 铁律

> **本稿是【视频逐字稿】，不是讲义。**
> 一个人对着镜头说话，念出来必须像人在讲，不是像人在念。
> 凡是需要用眼睛看才懂的东西——表格、罗列、分区标题——一律不许出现。
> 互动性必须强，而且必须是当题写的，不许套模板。

这条印在检察官每次运行的第一行。

### 用法

```bash
python3 tools/语法检察官.py                    # 全部课程：构建→审查→修正→重建→复审
python3 tools/语法检察官.py 03 05              # 只处理指定课次
python3 tools/语法检察官.py --check            # 只审查，不修正
python3 tools/语法检察官.py --commit           # 全部合格后自动提交
python3 tools/语法检察官.py --watch            # 守候：源码一改动就自动跑
python3 tools/语法检察官.py --rules            # 查看当前规则库与学习记录
python3 tools/语法检察官.py --learn <类别> <内容> [原因] [来源]
```

### 它会自己学

所有规则不写死在代码里，存在 [`tools/铁律.json`](tools/铁律.json)。每踩一个新坑，登记一次，此后永久生效：

```bash
python3 tools/语法检察官.py --learn 违禁 "太棒啦" "低龄化感叹" "第01课"
python3 tools/语法检察官.py --learn 术语 "because 是连词" "应称引导词"
python3 tools/语法检察官.py --learn 互动 "你品品" "口语引导词，应计入互动"
python3 tools/语法检察官.py --learn 硬伤 "lie 与 lay 同为三字母，长短记忆法失效"
```

类别：`违禁` / `术语` / `互动` / `承接` / `硬伤`。
每登记一条，规则库版本 +1，并写入学习记录（日期、来源、教训、落地方式）。

规则库当前收录：**违禁词 28 条 · 术语红线 12 条 · 互动词 55 个 · 承接词 24 个 · 硬伤 9 条**，
以及 11 条学习记录——全部来自实际踩过的坑。

每次审查结果自动留档到 `tools/审查日志.md`，便于回看哪类问题在反复出现。

### 不可代笔项

**互动密度、逐题互动这两项，机器不代笔。**

这是花代价买来的教训：曾为凑指标往七节课机械插入同样几句模板话，共 265 处，
结果读起来更像机器人。现在检出互动不足只会退回，并提示：

> 互动不足属内容问题，机器不代笔。
> 请按当题学情手写：预判学生会怎么错、用他的话说出来、给具体场景。

那几句模板话本身也已列入违禁词。

### 审查的 11 类规则

违禁词 · 术语红线 · 罗列体 · 题量规格 · 题面格式 · 题目衔接 ·
先报答案 · 互动密度 · 逐题互动 · 段落承接率 · 句长书面化

**任何一项不合格即退回重做。**

### 标准样板

**[Level 1 第 03 课](docs/Level1/高中英语语法切片-Level1-第03课-宾语表语宾语补足语.docx)** 为全套课程的标准样板，
已通过检察官全部 11 项检查。此后每一节的体例、讲法、互动密度、术语口径，一律对齐这一节。

样板的关键特征：

- 讲题一律 **动作 → 依据 → 结论**，答案永远是推理的最后一句
- 互动密度 12.0/千字：提问、让学生动手、预判他的错误、替他说出心里话
- 段落承接率 19%：每段开头用「好／那／来／别急／接着看」承上，不硬切
- 平均句长 13 字：短句为主，留气口
- 14 道题全部原创，题题有口语衔接

### 制作标准

完整规则见 **[语法检察官 · 制作标准](语法检察官-制作标准.md)**，共八条。核心三件事：

1. **这是逐字稿不是讲义** —— 禁表格、禁罗列、禁低龄化包装
2. **讲题必须动作→依据→结论** —— 不许上来甩答案，必须有互动，段落要丝滑
3. **术语与判断工具全套一以贯之** —— 连词只指并列连词、谓语看时态、加 be 动词检验法等

另附**已知硬伤清单**，记录已踩过的坑（lie/lay 记忆法、let/have 被动、-ly 结尾等），不许再犯。
