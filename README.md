## 制作标准与质检

全部 180 节统一遵循 **[语法检察官 · 制作标准](语法检察官-制作标准.md)**。

每节交付前必须通过自动检查：

```bash
python3 tools/inspector.py docs/Level1/某课.docx    # 检查单节
python3 tools/inspector.py --all                    # 检查全部
```

检查器覆盖 11 类规则：违禁词、术语红线、罗列体、题量规格、题面格式、题目衔接、
先报答案、互动密度、逐题互动、段落承接率、句长书面化。任何一项不合格即退回重做。

标准共八条，核心是三件事：

1. **这是逐字稿不是讲义** —— 禁表格、禁罗列、禁低龄化包装
2. **讲题必须动作→依据→结论** —— 不许上来甩答案，必须有互动，段落要丝滑
3. **术语与判断工具全套一以贯之** —— 连词只指并列连词、谓语看时态、加 be 动词检验法等

另附**已知硬伤清单**，记录已踩过的坑（lie/lay 记忆法、let/have 被动、-ly 结尾等），不许再犯。
