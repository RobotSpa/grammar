## 语法检察官

**一个会自我进化的 Python 智能体，单文件自持。**
铁律、全部规则、全部记忆，都焊在 `tools/语法检察官.py` 本体内，不依赖任何外部文件。

### 铁律

> **本稿是【视频逐字稿】，不是讲义。**
> 一个人对着镜头说话，念出来必须像人在讲，不是像人在念。
> 凡是需要用眼睛看才懂的东西——表格、罗列、分区标题——一律不许出现。
> 互动性必须强，而且必须是当题写的，不许套模板。

这段写死在源码里，外部改不动，每次运行第一屏就打出来。

### 用法

```bash
python3 tools/语法检察官.py                    # 构建 → 审查 → 自动修正 → 重建 → 复审
python3 tools/语法检察官.py 03 05              # 只处理指定课次
python3 tools/语法检察官.py --check            # 只审查
python3 tools/语法检察官.py --commit           # 全部合格后自动提交
python3 tools/语法检察官.py --watch            # 守候：源码一改动就自动跑
python3 tools/语法检察官.py --rules            # 查看铁律、硬伤清单与进化记录
python3 tools/语法检察官.py --learn <类别> <内容> [原因] [来源]
```

### 自我进化

两种方式，一手动一自动。

**手动登记　`--learn`**

```bash
python3 tools/语法检察官.py --learn 违禁 "众所周知" "书面套话，口播里没人这么说"
python3 tools/语法检察官.py --learn 硬伤 "长句要在句号处断开，不要一句到底"
```

`--learn` 会**直接改写 `语法检察官.py` 自己的源码**——找到文件里的铁律区，
把新规则写进去，版本号 +1。下次运行立刻生效，不需要改任何代码。

**自动进化　`--evolve`**

```bash
python3 tools/语法检察官.py --evolve            # 自己从稿子里长出新规则
python3 tools/语法检察官.py --evolve --commit   # 进化后自动提交
```

**不用人教。**它以「已定稿的合格稿」为黄金样本，自己完成四件事：

| 动作 | 做法 | 是否自动写入 |
|---|---|---|
| **词表进化** | 从合格稿里发现新的互动说法与承接词 | ✅ |
| **阈值自校准** | 把标准提到合格稿的实际水平 | ✅ |
| **风险统计** | 从审查日志统计哪类问题最常犯，排优先级 | ✅ |
| **违禁候选** | 找出只在退回稿出现、合格稿从不用的表达 | ❌ 只提示，需人工确认 |

实测三轮连续进化：

```
第1轮  互动密度 8 → 9   承接率 12 → 14   互动词 +7  承接词 +4
第2轮  互动密度 9 → 10  承接率 14 → 16
第3轮  互动密度 10 → 12
第4轮  互动密度 12 → 13
```

**标准自己越收越紧，三份合格稿始终没被卡死。**

这靠两道保护实现：

1. **留两成余量**——新阈值只取合格稿最低值的八成，不贴着最低线走
2. **单次涨幅封顶两成**——防止一步跳到极端把自己卡死

调试时踩过这个坑：第一版直接取「合格稿最低值 × 0.95」，
结果阈值一跳到 14 和 23，**三份合格稿全部变成不合格，进化直接自毁**。

另外两处误判也修了：**「你的」被当成互动词**（那只是代词不是互动指令），
**「主语是」被当成承接词**（那是内容不是转场），
**违禁候选里全是「主谓宾」「主系表」这类语法术语**（术语不是违禁词）。

**实测能力**：往干净稿里注入 8 种典型错误，**检出 7 种**；干净稿零误报。
漏检的一种是「缺做题缓冲」——注入点附近仍有其他停顿词，属阈值边界情况。

**🚫 不代笔**是刻意划的边界。曾为凑指标机械插入 265 处模板互动句，读起来更像机器人。
现在这几类检出只退回，提示人工重写。**自动修复保底线，人写保上限。**

### 机器查不到的三件事（必须人工核）

1. **考点配比**——讲了三条判断标准，题目就该在三条上大致均衡
2. **课前测覆盖度**——六道题要覆盖全部考点，同一考点不重复出两道
3. **是否有综合题**——至少一道要同时用到两条以上标准

### 标准样板

**[Level 1 第 03 课](docs/Level1/高中英语语法切片-Level1-第03课-宾语表语宾语补足语.docx)** 为全套课程的标准样板，
已通过检察官全部 11 项检查。此后每一节的体例、讲法、互动密度、术语口径，一律对齐这一节。

样板的关键特征：

- 讲题一律 **动作 → 依据 → 结论**，答案永远是推理的最后一句
- 互动密度 12.0/千字：提问、让学生动手、预判他的错误、替他说出心里话
- 段落承接率 19%：每段开头用「好／那／来／别急／接着看」承上，不硬切
- 平均句长 13 字：短句为主，留气口
- 14 道题全部原创，题题有口语衔接

### 制作标准

完整规则见 **[语法检察官 · 制作标准](语法检察官-制作标准.md)**，共八条。核心三件事：

1. **这是逐字稿不是讲义** —— 禁表格、禁罗列、禁低龄化包装
2. **讲题必须动作→依据→结论** —— 不许上来甩答案，必须有互动，段落要丝滑
3. **术语与判断工具全套一以贯之** —— 连词只指并列连词、谓语看时态、加 be 动词检验法等

另附**已知硬伤清单**，记录已踩过的坑（lie/lay 记忆法、let/have 被动、-ly 结尾等），不许再犯。
